## Atividade - Calculadora de Média Escolar

### Objetivo

Desenvolver uma aplicação flutter capaz de receber o nome de um aluno, calcular sua média e apresensar a situação escolar


### Conceitos

- MaterialApp
- Scaffold
- StatefulWidget
- TextField
- TextEditingController
- ElevatedButton
- OutlineButton
- SetState
- Variáveis
- Conversão de texto para número
- Condicionais
- Funções
- Validação de campos
- SnackBar


### Criar o Projeto FLutter


```bash
flutter create media_escolar

```

Entre na pasta do projeto:
```bash
  cd media_escolar
```

Abra o projeto no Visual Studio Code:
```bash
  code .
```

Execute o projeto:
```bash
  flutter run
```
